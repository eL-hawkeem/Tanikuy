# Spark - Free Bootstrap 5 Admin Dashboard Template (Design System in Markdown)

## Overview
Spark Admin is a modern executive dashboard template built on a high-contrast Forest Green and Electric Neon Lime color palette.

All pages, layout structures, and design tokens are documented in clean Markdown (`.md`) format.

## Design System & Page Specifications
